## Tech Stack

- **Framework**: Next.js 16.2.10 (App Router) & React 19
- **Styling**: TailwindCSS v4 & shadcn/ui
- **State & API**: Redux Toolkit & RTK Query
- **Authentication**: better-auth with Keycloak OIDC/PKCE
- **Animations**: motion/react (Motion v12)
